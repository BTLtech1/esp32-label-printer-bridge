Install BTL Print Bridge

Turns an ESP32-S3 into a Wi-Fi bridge for a USB label printer. No software to install: this page flashes the board for you.

  1. Use Chrome or Edge on a computer.
  2. Plug the board's UART (or "COM") USB port into your computer.
  3. Click Install and pick the board's port from the list.

This browser can't flash boards. Open this page in Chrome or Edge on a computer. Open this page over https to install.

If no port appears, try another USB cable (some only charge). If it can't connect, hold the board's BOOT button while you click Install.

After installing
  1. On your phone or computer, join the Wi-Fi network BTL-Printer-Setup.
  2. A setup page opens (or go to http://192.168.4.1). Enter your 2.4 GHz Wi-Fi and save.
  3. Plug your printer into the board's USB port and open http://btl-printer.local.

Source, wiring and full guide: github.com/BTLtech1/esp32-label-printer-bridge
